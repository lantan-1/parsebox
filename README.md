# ParseBox 解析盒 · 本地解析工具 v6.2

模仿 ParseDock 的三步流程，全部在本机运行，不经过任何第三方服务器：
**粘贴链接 → 解析 → 选清晰度 → 下载原视频 / 原图 / 音频。**

底层是开源工具 yt-dlp，一个软件支持国内外主流平台（抖音、B站、小红书、快手、微博、西瓜、YouTube、TikTok、Instagram、X 等），完整清单见 `PLATFORMS.md` 或软件里的“支持平台”按钮。

**v2 新增**：① ffmpeg 已内置（靠 imageio-ffmpeg 包自带二进制），不用再单独安装就能合并 B站的音视频双轨、转 MP3；② 多路 Cookie 尝试。**实测结论（2026-11）**：抖音自领访客 Cookie 已被平台校验拒绝；Chrome 与新版 Edge 的 Cookie 又被“应用绑定加密”锁死，外部程序能读出库、解不开值。抖音拿 Cookie 的可靠办法只有两条，见下面“必读”一节（扩展导出 cookies.txt，或 Firefox）。

**v6.2 新增**：批量解析下载。点“批量解析”，一次粘贴多条链接或多段分享文案（可混排抖音、B站、YouTube 等多个平台，最多 30 条），逐条自动解析；解析完点“批量下载（全部最高画质）”逐条下载，也可在列表里选中某一条单独下载；中途可点“停止批量”。另新增“同时下载字幕（B站/YouTube）”勾选。

## 怎么运行（二选一）

1. **直接跑（已有 Python）**：双击 `run.bat`，首次会自动装 yt-dlp 和 imageio-ffmpeg，然后打开界面。
2. **打包成 exe**：双击 `build_exe.bat`，完成后 `dist\ParseBox.exe` 就是单文件软件（已内置 ffmpeg），可拷到任何 Windows 电脑双击运行（对方电脑不用装 Python、不用装 ffmpeg）。

## 使用步骤

1. 在抖音/B站点“分享 → 复制链接”，把整段分享文案直接粘贴进来（软件会自动从文案里挑出链接；只粘一个 BV 号也能识别）。
2. 点“解析”，等列表出来。
3. 在列表里选一条（最高画质 / 指定清晰度 / 仅音频 / 封面原图 / 图集原图），点“下载所选”，或直接双击条目。
4. 文件默认存到 `下载\解析下载` 文件夹，可在界面里改。

## 必读：Cookie 与清晰度

- **抖音（重要）**：yt-dlp 提取器已被 `a_bogus` 签名墙挡住，弃用。实测：服务器对纯脚本请求会把作品数据置空（`aweme:null` 空壳页），只有真浏览器执行页面 JS 后数据才加载。**v5 起使用档案模式，v6 起自动触发**：软件在 `%LOCALAPPDATA%\ParseTool\EdgeProfile` 维护专属 Edge 档案；解析抖音时若档案还没有登录态，会**自动弹出**专属 Edge 窗口让你扫码登录一次，登录成功后自动接着把刚才那条链接解析完。之后全程免导出、免选 Cookie（通常数月有效，失效时下次解析会再自动弹扫码）。首次若已有 cookies.txt，软件会先把它的登录态灌入档案，可能连码都不用扫。档案不可用时自动回退到临时浏览器模式（注入 cookies.txt）与页面直抓。档案与日常 Edge 完全隔离，互不影响。
- **B站**：不登录最高一般到 720p/1080p（视视频而定）；想下 1080p+、4K，要导入已登录（大会员）账号的 Cookie。软件不绕过付费/会员权限，会员内容仍需你自己的会员账号。
- **YouTube**：偶尔触发机器人校验时同样把 Cookie 来源切到你的浏览器即可。
- **其他需要登录的平台（v6.2）**：解析失败时，软件会自动改用专属浏览器档案里该网站的 Cookie 重试；档案里没有登录态时，会打开专属窗口让你登录一次（登录后关闭窗口即继续），之后该网站同样免导出。与抖音共用同一个专属档案目录，互不影响日常浏览器。

## ffmpeg 已内置（v2 起不用装）

软件查找 ffmpeg 的顺序：程序同目录 → imageio-ffmpeg 自带二进制 → 系统已安装的 ffmpeg，界面右上角会显示来源。B站双轨合并、音频转 MP3 都靠它，全程自动。若右上角显示“未找到”，重跑一次 `run.bat` 把依赖装全即可；也可以把任意 `ffmpeg.exe` 放到程序同目录。

## 已知限制

- 抖音图文（图集）帖：yt-dlp 对部分图文帖支持不完整，能抓到的原图会出现在列表的“图集原图”条目里；抓不到的把具体链接单独反馈再想办法。
- 解析结果取决于平台当时返回什么：平台改接口时，先升级 yt-dlp 往往就修好：`pip install -U yt-dlp`。
- 下载内容请仅供个人学习使用，尊重原作者版权，不要商用或二次发布。

## 文件说明

- `ParseTool.py` 主程序（界面＋解析＋下载，单文件）
- `PLATFORMS.md` 国内外支持平台清单
- `run.bat` 一键运行
- `build_exe.bat` 一键打包 exe（内置 ffmpeg）
- `requirements.txt` 依赖清单（yt-dlp、imageio-ffmpeg）
- `test_logic.py` 纯逻辑自测（链接提取、清晰度整理、原图收集、内置 ffmpeg 与自动 Cookie）
