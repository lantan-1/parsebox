# ParseBox 解析盒

**Windows 本地链接解析下载工具** —— 粘贴抖音、B站、YouTube 等平台的链接（或整段分享文案），
解析出**原视频（多清晰度可选）、封面原图、图集原图、仅音频**，在本机直接下载。
全部解析与下载都在你自己的电脑上完成，不经过任何第三方解析服务器。

当前版本：**v6.1** ｜ 平台：Windows 10/11 ｜ 运行时：Python 3.10+（实测 3.14）

---

## 功能与支持平台

- **三步流程**：粘贴链接 → 解析 → 在列表里选清晰度/原图 → 下载（带进度、速度显示）
- **粘贴即识别**：整段分享文案自动提取链接；B站裸 BV 号也能直接识别
- **条目齐全**：最高画质自动（自动合并音视频）、各档清晰度（同档去重只留最好）、
  仅音频（可转 MP3）、封面原图（自动取最大尺寸）、图文帖图集原图
- **批量解析下载（v6.1 新增）**：一次粘贴多条链接/多段分享文案（混排抖音、B站、
  YouTube 等多个平台，最多 30 条），逐条自动解析；一键批量下载（每条最高画质），
  也可单独下载任意一条；中途可停止
- **抖音专属档案**：软件维护一个与日常浏览器隔离的专属 Edge 档案，登录一次长期
  有效；没登录时解析流程会**自动弹出扫码窗口**，登完自动接着解析

支持平台（完整清单见 [PLATFORMS.md](PLATFORMS.md)，引擎共覆盖 1000+ 站点）：

| 范围 | 平台 |
|---|---|
| 国内 | 抖音、B站、快手、微博、西瓜视频、今日头条、AcFun、网易云音乐、喜马拉雅；小红书/知乎/斗鱼/虎牙部分可用 |
| 国外 | YouTube、TikTok、X、Reddit、Vimeo、Dailymotion、Twitch、Pinterest、Tumblr、VK、Niconico、SoundCloud |
| 不支持 | 微信视频号（无公开接口）、优酷/腾讯/爱奇艺等会员 DRM 内容、Netflix/Disney+/Spotify 等 DRM 平台 |

原则：只解析你有权访问的内容，不绕过付费与 DRM；会员清晰度（如 B站 4K）需要你自己的会员账号。

## 技术栈

| 组件 | 用途 |
|---|---|
| Python 3 + tkinter | 主程序与界面（单文件 `ParseTool.py`，零构建） |
| yt-dlp | 通用平台解析引擎（除抖音外的平台） |
| imageio-ffmpeg | 自带 ffmpeg 二进制：免安装合并音视频双轨、音频转 MP3 |
| Playwright（驱动本机 Edge/Chrome） | 抖音浏览器/档案模式：真浏览器打开视频页抓数据 |
| urllib / http.cookiejar | 抖音页面抓取、Cookie 文件处理、直链流式下载 |

## 实现原理

### 通用平台
链接经 yt-dlp 提取格式列表，软件按“同清晰度（高+帧率）只保留码率最好的一条”
整理成下载条目；分离的音视频轨由内置 ffmpeg 无损合并（`-c copy`）。

### 抖音
1. **yt-dlp 提取器已不可用**：抖音网页详情接口上了 `a_bogus` 签名墙，yt-dlp 未实现
   该签名，有效的登录 Cookie 也会报 `Fresh cookies are needed`（上游 #9667）。
2. **纯 HTTP 抓页面也拿不到数据**：服务器对非浏览器请求返回 862KB 的**空壳页面**，
   作品数据字段是 `aweme:null`；数据只在真浏览器执行页面 JS 后、由签名接口加载。
3. **浏览器读 Cookie 此路不通**：Chrome 与新版 Edge 采用应用绑定加密
   （App-Bound Encryption），Cookie 库能读出条数、值解不开（DPAPI 错误），
   任何外部程序都无法直接借用日常浏览器的登录态。
4. **当前实现：专属档案 + 浏览器抓取**：软件用 Playwright 驱动用户电脑上的
   Edge，使用一个**专属持久档案**（`%LOCALAPPDATA%\ParseTool\EdgeProfile`）保存
   登录态；打开视频页后监听页面自己发出的 `aweme/v1/web/aweme/detail` 接口返回，
   拿到全清晰度数据；再以直链方式（带 UA/Referer/Cookie）流式下载。
   档案与日常 Edge 完全隔离，登录一次通常数月有效。

## 快速开始

**环境要求**

- Windows 10/11（已实测；其他系统见下方“系统与版本支持”）
- Python 3.10 或更高（官网安装时勾选 Add to PATH；实测环境为 3.14）
- Microsoft Edge 或 Chrome 任一（抖音档案模式驱动它打开页面；Edge 优先）
- 首次运行需联网安装依赖（yt-dlp、imageio-ffmpeg、playwright，脚本自动完成）

**方式一：直接运行**

1. 下载/克隆本仓库
2. 双击 `run.bat` —— 首次自动安装依赖，然后打开界面

**方式二：打包成 exe（可选）**

双击 `build_exe.bat`，完成后 `dist\ParseBox.exe` 为单文件程序（内置 ffmpeg），
可拷到其他 Windows 电脑双击运行（对方仍需装 Edge/Chrome 供抖音模式使用）。

## 使用教程

1. 在抖音/B站等 App 或网页点“分享 → 复制链接”
2. 把整段文案粘贴到软件的链接框（软件自动提取其中的链接），点**解析**或按回车
3. 列表出现后选一条（双击条目也可），点**下载所选**；文件默认存到
   `下载\解析下载`，可在界面修改目录

**抖音首次使用**：直接粘贴链接解析即可。若专属档案还没有登录态，软件会自动弹
出一个 Edge 窗口，扫码登录一次抖音，登录成功后自动继续解析。之后长期免操作。
（老用户也可先把扩展导出的 cookies.txt 放在下载文件夹，软件会自动识别并把登录
态灌入档案，可能连码都不用扫。）

**批量模式**：点界面上的“批量解析”，把多条链接（一行一条或整段文案）粘进去开始；
全部解析完后点“批量下载（全部最高画质）”逐条下载到保存目录，日志会逐条报告
成功/失败；批量过程中可随时点“停止批量”（当前一条处理完后停）。

**B站清晰度**：未登录最高约 720p/1080p（视视频而定）；1080p+、4K 需在界面
“Cookie 来源”里提供已登录（大会员）账号的 Cookie（浏览器或 cookies.txt 文件）。

## 常见问题

- **抖音报 “Fresh cookies are needed”** —— 这是 yt-dlp 的老报错路径；正常情况
  抖音会先走档案模式。若最终仍失败，把软件日志发给开发者定位。
- **Chrome/Edge 的 Cookie 读不出来（DPAPI / Could not copy）** —— 应用绑定加密与
  运行时锁库的已知限制（见实现原理），抖音请用档案模式，其他平台可用
  cookies.txt 文件方式。
- **解析时弹出的 Edge 窗口是什么** —— 软件专属档案的登录窗口，只在需要登录时
  出现，与日常 Edge 互不影响；关掉窗口即取消本次登录。
- **下载的视频没有声音** —— ffmpeg 未就绪时分离轨道无法合并；重跑 `run.bat`
  补齐依赖（界面右上角会显示 ffmpeg 来源）。

## 系统与版本支持

- **Windows 10/11**：完整支持并实测（当前 v6.1）。
- **macOS / Linux**：主程序为跨平台 Python 理论上可运行（tkinter 界面、yt-dlp、
  Playwright 均跨平台），但未做系统性实测，抖音档案路径与浏览器通道按 Windows
  优先适配；正式版开发中。
- **Android**：独立 App 版开发中（Kotlin + WebView 档案方案）。
- **iOS**：受系统与商店政策限制（无法内置同类下载引擎），在评估中。
